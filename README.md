# Quantitative Methods I — seminar materials

Source for the course website, autumn 2026.
Course: *Quantitative Methods* (SHRG.03.024), Johan Skytte Institute of Political Studies, University of Tartu.

**The site:** <https://martinmolder.github.io/quantitative-methods-i/>

## What is here

```
_quarto.yml            book configuration
index.qmd              front page
NN-*.qmd               one file per seminar, 15 in all
styles.css             site styling
data/                  the files students download
data-raw/              scripts that build data/ from the CSES source
swirl/                 the swirl course, one lesson per seminar
tools/                 checks run over the chapters before release
docs/                  rendered site — this is what GitHub Pages serves
```

The lecture slides are kept separately and are not part of this repository.

## Building

Rebuild the data (only needed if the CSES source or the recoding changes):

```
Rscript data-raw/01_extract_sweden.R
Rscript data-raw/02_build_sweden.R
Rscript data-raw/03_codebook.R
Rscript data-raw/04_turnout.R
Rscript data-raw/05_countries.R
```

Rebuild the swirl course:

```
Rscript tools/build_swirl_zip.R
```

Render the site, then commit `docs/`:

```
quarto render
```

## Checking

```
Rscript tools/check_all.R
```

Runs eight checks over the materials: that every function and argument is
explained before it is used, that no number in the text is typed by hand,
code style, the measurement-scale rule, chapter balance, encoding, the swirl
lessons, and that the lecture slides match the chapters.

`REGISTER.md` lists every function and argument the materials introduce, in
the order they first appear. It is generated by `tools/check_firstuse.R`.

## Data

CSES Module 6, Second Advance Release (16 December 2025), Sweden 2022.
2,845 respondents, eight parliamentary parties.

> The Comparative Study of Electoral Systems (www.cses.org). CSES MODULE 6
> SECOND ADVANCE RELEASE [dataset and documentation]. December 16, 2025
> version. doi:10.7804/cses.module6.2025-12-16

The 86 MB source file is not in this repository.
`data-raw/01_extract_sweden.R` expects it at `../CSES module 6/cses6.csv`.

`data/world.csv` is built from the World Bank Open Data API by
`data-raw/05_countries.R`.
